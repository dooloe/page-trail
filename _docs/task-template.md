# PageTrail — Task Template

Use this template when creating or refining a GitHub issue. Keep implementation progress and task details in the issue rather than duplicating them in the local backlog.

```markdown
## Goal

Describe the concrete outcome of this task.

## Scope

- List the behavior or artifacts to implement.
- State any boundaries needed to keep the task focused.

## Prerequisites

- Link any issues that must be completed first, or write “None.”
- Identify any new dependencies that require user approval before installation.

## Acceptance criteria

- Describe observable results that demonstrate completion.

## Verification

- Specify the relevant tests and commands to run.
- Include manual checks when needed.
```

Use the [product plan](./plan.md) and [architecture](./architecture.md) to define scope, and follow the [development process](./process.md) during implementation. Include only checks relevant to the task.
